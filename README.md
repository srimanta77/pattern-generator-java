# 📐 Multi Pattern Generator (Java)

This project is developed as part of the Software Development Internship at Cognifyz Technologies.

## 📌 Task 2
Generate and print different types of number and star patterns using loops.

## 🎯 Features
- Menu-driven pattern selection
- Number Triangle
- Star Square
- Right Triangle Star
- Inverted Triangle
- Floyd’s Triangle
- User input for rows

## 🛠️ Technology Used
- Java
- VS Code

## ▶️ How to Run

Compile:
javac PatternGenerator.java

Run:
java PatternGenerator
